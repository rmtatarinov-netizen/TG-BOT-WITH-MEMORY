# Telegram-бот с короткой и долгой памятью

Один бот на aiogram + OpenAI-совместимом API, который объединяет два режима памяти:

- **Короткая память** — помнит последние 10 пар сообщений (10 вопросов + 10 ответов) для каждого пользователя в оперативной памяти и учитывает их в диалоге.
- **Долгая память** — принимает документы PDF/TXT/DOCX, индексирует их в ChromaDB и отвечает на вопросы по содержимому (RAG).

## Возможности

- Обычный диалог с учётом последних сообщений.
- Загрузка документов прямо в чат: файл скачивается, разбивается на чанки по 500 символов с перекрытием 50 и сохраняется в векторную базу.
- Ответы на вопросы по документам; при необходимости используются оба типа памяти одновременно.
- Личные документы видны только их владельцу, общие (`shared`) — всем пользователям.
- Длинные ответы автоматически делятся на части по 4000 символов (лимит Telegram — 4096).
- Документы и векторная база сохраняются между перезапусками в папках `uploads/` и `memory/`.
- Короткая память хранится только в RAM и очищается при перезапуске бота.

## Команды бота

| Команда | Действие |
| --- | --- |
| `/start` | Приветствие и краткая инструкция |
| `/help` | Справка по использованию |
| `/reset` | Очистить короткую память (историю диалога) |

## Требования

- Python 3.10+
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather)
- API-ключ ProxyAPI (или другого OpenAI-совместимого провайдера)

## Установка

Запускать команды из папки проекта.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Настройка `.env`

Создайте файл `.env` из примера и заполните значения:

```powershell
Copy-Item .env.example .env
```

```dotenv
# --- Telegram ---
BOT_TOKEN=123456789:AA...your_bot_token
# Если api.telegram.org недоступен напрямую (VPN/прокси):
# TELEGRAM_PROXY=http://127.0.0.1:12334

# --- OpenAI / ProxyAPI ---
PROXYAPI_API_KEY=sk-...your_api_key
PROXYAPI_BASE_URL=https://api.proxyapi.ru/v1

# --- Модели (необязательно) ---
EMBED_MODEL=text-embedding-3-small
CHAT_MODEL=gpt-4o-mini
OPENAI_MODEL=gpt-4o-mini
```

| Переменная | Обязательна | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `BOT_TOKEN` | да | — | токен Telegram-бота |
| `TELEGRAM_PROXY` | нет | — | прокси для Telegram (`http://…` или `socks5://…`) |
| `PROXYAPI_API_KEY` | да | — | ключ API |
| `PROXYAPI_BASE_URL` | нет | URL провайдера по умолчанию | базовый URL API |
| `EMBED_MODEL` | нет | `text-embedding-3-small` | модель эмбеддингов |
| `CHAT_MODEL` | нет | `gpt-4o-mini` | модель ответов |
| `OPENAI_MODEL` | нет | `gpt-4o-mini` | запасное имя модели, если `CHAT_MODEL` не задан |

`.env` подхватывается автоматически через `python-dotenv`, поэтому запускайте бота из папки проекта. Файл `.env` содержит секреты — не публикуйте его и не коммитьте в git.

## Запуск

```powershell
    python bot.py
```

Бот работает через long polling и не требует вебхука. Запускать нужно только один процесс `bot.py`.

## Как пользоваться

1. Отправьте `/start`.
2. Напишите вопрос или отправьте голосовое сообщение — бот ответит с учётом последних сообщений диалога.
3. Администратор из списка `ADMIN_IDS` может отправить документ PDF, TXT или DOCX — он попадёт в общую базу знаний.
4. Дождитесь сообщения «Документ … сохранён и проиндексирован. Чанков: N».
5. Задавайте вопросы по документу — бот найдёт релевантные фрагменты и учтёт историю диалога.
6. `/reset` очищает историю диалога.

## Общие документы (shared)

Чтобы документ был доступен всем пользователям бота (например, прайс или условия страхования), проиндексируйте его из командной строки:

```powershell
python index_shared_document.py путь_к_документу.pdf
```

Скрипт создаёт эмбеддинги и сохраняет документ в ChromaDB с меткой `shared`. Повторный запуск добавит документ ещё раз — при необходимости удалите папку `memory/` и проиндексируйте файлы заново.

Документы также можно добавлять через админский чат бота: пользователи из `ADMIN_IDS` индексируют отправленные файлы в общую базу.

## Ограничения

- Короткая память не переживает перезапуск бота.
- Поддерживаются `PDF`, `TXT`, `DOCX`; старый бинарный `.doc` не читается (python-docx его не поддерживает).
- Для ответа используются top-5 найденных фрагментов; полный документ в модель не передаётся.
- Команды полной очистки базы нет — можно удалить личные документы через `/reset_docs` или всю папку `memory/`.
- Общие документы (`shared`) видны всем пользователям; личные документы, загруженные в чат, видны только их владельцу.

## Частые проблемы

**`Не задана переменная окружения BOT_TOKEN` / `PROXYAPI_API_KEY`**
Добавьте значения в `.env` и убедитесь, что файл сохранён.

**`TelegramNetworkError: Cannot connect to host api.telegram.org:443`**
Нет доступа к Bot API. Подключите VPN или укажите прокси в `.env`:
`TELEGRAM_PROXY=http://127.0.0.1:12334` (HTTP/SOCKS5-прокси, например Hiddify).
Для `socks5://` нужен пакет `aiohttp-socks` (входит в `requirements.txt`).
Проверка: `curl.exe --proxy http://127.0.0.1:12334 https://api.telegram.org/bot<TOKEN>/getMe`.

**Ошибка 401 Unauthorized**
Неверный `PROXYAPI_API_KEY`.

**Ошибка 404 / запросы уходят не туда**
Проверьте `PROXYAPI_BASE_URL` (например, `https://api.proxyapi.ru/v1`).

**`Для PDF требуется пакет pypdf` / `Для DOCX требуется пакет python-docx`**
Установите зависимости: `python -m pip install -r requirements.txt`.

**Переменные из `.env` не подхватываются**
Запускайте бота из папки проекта, где лежит `.env`.

**`ModuleNotFoundError`**
Активируйте виртуальное окружение и установите зависимости из `requirements.txt`.
